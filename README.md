# かんたん家計簿

ブラウザだけで動く、シンプルな家計簿アプリです。ビルドやサーバーは不要で、データは端末内（localStorage）に保存されます。

## 機能

- 収入・支出の記録（日付・カテゴリ・金額・メモ）
- 月ごとの収入・支出・残高の自動集計
- 月フィルターで履歴を絞り込み
- 記録の削除
- データはブラウザに保存され、次に開いたときも残ります

## 使い方

`index.html` をブラウザで開くだけです。

```bash
# 例：ローカルサーバーで開く場合
python3 -m http.server 8000
# → http://localhost:8000 にアクセス
```

ファイルを直接ダブルクリックして開いても動作します。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の構造 |
| `style.css` | 見た目 |
| `app.js` | 記録の追加・削除・集計・保存のロジック |

## データについて

- 記録はお使いのブラウザの `localStorage` に保存されます。
- 別の端末やブラウザとは共有されません。
- ブラウザの履歴・サイトデータを消去すると記録も消えます。
